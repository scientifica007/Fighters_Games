# صراع العناصر — ولادة المبارزة (Duel Reborn v3)

**الصفحة الرئيسية:** https://scientifica007.github.io/Fighters_Games/

نسخة قتالية رأسية (Vertical Slice) جديدة مستوحاة من عمق ألعاب القتال الثنائية الكلاسيكية، بشخصيات أصلية من المشروع وليست نسخاً من Street Fighter أو King of Fighters. المشروع مفتوح المصدر ويعمل في المتصفح بدون مكتبات خارجية أو خادم.


## تحديث الهاتف والملامح — v3.1

بناءً على تجربة الهاتف الأفقية الفعلية، أُعيد توزيع أدوات التحكم:
- **يسار الحلبة:** سهمان للحركة، وقفز وصدّ، في شبكة 2×2 بحقول لمس أوسع.
- **يمين الحلبة:** هجوم سريع وثقيل وخاص وخارق، في شبكة 2×2 منفصلة.
- لا تحجب الأزرار أرضية الساحة في الوضع الأفقي، ويمكن الضغط المتزامن بإصبع من كل يد.
- في الوضع العمودي تبقى الحلبة أعلى منطقتَي التحكم المتجاورتين، لضمان عرض مقبول.
- **المبارزة بين لاعبين:** لوحة المفاتيح تدعم الشخصيتين، أما تحكم اللمس في النسخة الحالية فيخص اللاعب الأول؛ إذا رغب لاعبان باللعب على الهاتف نفسه فالحل الأفضل دعم وحدتي تحكم مستقلتين مستقبلاً.

أعدنا رسم وجهي المقاتلين بدل إعادة تلوين الوجه نفسه: **آزر** وجه زاوي وعينان زرقاوان رماديتان وشعر فضي وندبة ولحية خفيفة؛ **نارا** وجه مستدير وعينان خضراوان وشعر برتقالي مربوط ونمش وحلية أذن. تظهر نسختان مكبرتان من الوجهين في واجهة الصحة. كما عُدّل إيقاع المشي واستُخدم استيفاء بين وضعيات الاستعداد والاصطدام والمتابعة لكل ضربة، من دون تغيير توقيت Hitbox في المحرك.

الاختبارات: ترتيب أزرار التحكم، الضغط متعدد الأصابع، الإفلات عند إيقاف اللعب، الوجهين، اختبار Canvas تلقائي، واختبارات المحرك والتوازن. الرسوم متجهية أصلية وليست صور شخصيات من ألعاب تجارية.

## لماذا بدأنا بشخصيتين؟

نسخة v3 **إعادة تأسيس** لمحرك القتال والرسوم، وليست استبدال الوجوه بشكل سطحي. جرى التركيز على آزر ونارا وساحة واحدة متقنة قبل زيادة المحتوى. تتوافر النسخة السابقة التي تضم سبع شخصيات ومراحلها على الرابط:

**https://scientifica007.github.io/Fighters_Games/classic/**

## ماذا تقدم النسخة الجديدة؟

- شخصيتان أصليتان: **آزر / نصل البرق** (سيف وصاعقة بعيدة المدى)، و**نارا / لهيب الشفق** (قتال قريب واندفاع).
- رسوم متحركة من إطارات (frame sprites) مولّدة مسبقاً في ذاكرة Canvas لكل وضعية، مع تفاصيل هيئة وملابس وشعر وسلاح منفصلة، لا رسوم أشخاص بسيطة.
- حلبة **قلعة الفجر** الأصلية ذات طبقات ثابتة مخزنة مؤقتاً وتأثيرات جزيئات وستائر متحركة.
- نزال أفضل جولتين من ثلاث، إحصاءات مشتركة للشخصيتين، حركة وقفز وصدّ وضربات خفيفة وثقيلة ومهارات خاصة وخارقة.
- نظام 60Hz ثابت، **Frame Data** لبداية/نشاط/استعادة الحركة، **Hitboxes/Hurtboxes**، وصدّ وكسر حراسة وhitstop ومجموعات ضربات مع إلغاء حركة ضربة مصيبة إلى ضربة أقوى.
- مستوى صعوبة الذكاء الاصطناعي: مبتدئ ومتوسط ومتقدم دون مضاعفات إحصائية.
- لاعبان على لوحة مفاتيح واحدة. دعم لمس على الأجهزة المحمولة. مؤثرات قتالية اصطناعية اختيارية **دون موسيقى**.
- للمطور: الضغط على **B** أثناء اللعب يعرض مستطيلات الهجوم والإصابة.

| التحكم | اللاعب الأول | اللاعب الثاني |
|---|---|---|
| حركة | A / D | ← / → |
| قفز | W | ↑ |
| صدّ أو وضعية دفاع | S | ↓ |
| ضربة خفيفة | F | J |
| ضربة ثقيلة | G | K |
| مهارة خاصة (25 طاقة) | H | L |
| مهارة خارقة (100 طاقة) | U | O |
| إيقاف مؤقت | Esc أو P | Esc أو P |

**ملاحظة توازن:** لا يصح الادعاء بتكافؤ فوز 50% بين الشخصيتين دون اختبارات بشرية وتجارب Matchup؛ البيانات الأساسية متكافئة، لكن المدى والاندفاع قد يخلقان فروقاً تكتيكية تتطلب الضبط.

## التشغيل والاختبار

~~~bash

~~~

إذا توفر Node.js:

~~~bash

~~~

## الإصدار الكلاسيكي v2 — محفوظ

# صراع العناصر · Elemental Rivals

لعبة قتال ثنائية الأبعاد تعمل بالكامل داخل المتصفح، برسوم شخصيات أصلية مرسومة برمجياً على HTML5 Canvas. لا تحتاج إلى قاعدة بيانات أو حساب أو شبكة أثناء اللعب.

## اللعب

افتح [index.html](./index.html) على متصفح حديث، أو انشر المستودع عبر GitHub Pages. وقد تحتاج إلى تشغيل خادم ملفات محلي لأن اللعبة تستخدم وحدات JavaScript (ES modules):

~~~bash
python3 -m http.server 8000
~~~

ثم افتح http://localhost:8000 .

**الوضعان:**
- **الرحلة الفردية:** اختر واحداً من ستة مقاتلين، وواجه سبعة خصوم متصاعدة مهارتهم، وتنتهي الرحلة بمواجهة **نيكس، حارس البوابة**. أعلى مرحلة يتم الوصول إليها تُحفظ محلياً لكل مقاتل. يمكنك متابعة الرحلة أو إعادة بدئها.
- **القتال الثنائي المحلي:** يختار لاعبان شخصيتين من الشخصيات الست، ويتنافسان على الجهاز نفسه. الفائز بأول جولتين يفوز بالمباراة. يسمح بمرآة الشخصية نفسها.

## التوازن

تفرض النسخة الأولى مبدأ **التماثل العددي**: صحة جميع الشخصيات 100، وسرعة الحركة والقفز والضربات الأساسية مطابقة، وقيمة ضرر المهارة الخاصة وتبريدها متماثلتان (15 نقطة، 6.6 ثانية). تتفاوت مناطق التأثير والتوقيت والمنفعة التكتيكية وفق الشخصية. يزيد ذكاء خصوم القصة تدريجياً عبر **التوقيت والدفاع والمسافة**، وليس عبر مكافآت مخفية للصحة أو الضرر.

**مهم:** التماثل العددي لا يثبت أن كل مواجهة تمتلك احتمال فوز 50%. إثبات ذلك يحتاج إلى بيانات مباريات فعلية وتحليل matchups وضبط مستمر. تسمح بنية تعريف الشخصيات والتحكم باختبار هذه الفرضية لاحقاً.

## مكوّنات المشروع

- index.html: واجهة اللعبة العربية والمتجاوبة.
- style.css: تصميم الواجهة الداكنة.
- fighters.js: الشخصيات، المهارات، ثوابت التوازن، مراحل القصة.
- render.js: رسم شخصيات متمايزة بصرياً والساحة والمؤثرات والعدادات.
- game.js: محرك القتال والإدخال والذكاء الاصطناعي والحفظ والصوت.
- tests/balance.test.mjs: اختبارات قواعد التوازن.
- .github/workflows/ci.yml: فحوصات JavaScript والتوازن.

## خصوصية وإتاحة

- لعبة محلية بالكامل، دون اتصالات شبكية أو تحليلات أو أصول من أطراف ثالثة.
- يستخدم localStorage لحفظ المرحلة المكتملة فقط.
- أُخذت الحركة المخفضة في الحسبان في الواجهة؛ المؤثرات القتالية الرسومية جزء من المشهد.
- جميع الشخصيات والتصميمات أصلية لهذا المشروع.

**ملاحظة تشغيلية:** فتح index.html مباشرة بصيغة file:// قد يُحظر بسبب الاستيراد المحلي للوحدات في بعض المتصفحات. استعمل خادم الملفات المذكور أو GitHub Pages.

## نشر الموقع على GitHub Pages

يلزم تفعيل Pages **مرة واحدة من حساب مالك المستودع**. افتح **Settings → Pages** ثم اختر **Build and deployment → Source → GitHub Actions**. بعد حفظ الإعدادات افتح **Actions → Publish game to GitHub Pages → Run workflow**. سيكون عنوان الموقع عند اكتمال النشر: https://scientifica007.github.io/Fighters_Games/ . لا يعتبر الرابط حياً حتى ينجح سير عمل النشر.

## Visual Edition v2 — التحسين البصري (أكتوبر 2026)

أُعيد تصميم الطبقة الرسومية مع إبقاء قواعد القتال الأصلية دون تغيير:

- **7 ساحات خاصة:** البوابة الحجرية، حدائق الريح، حصن الفجر، مصنع اللهب، أزقة الظلال، برج العاصفة، العرش الأخير. لكل ساحة تصميم معماري وسُلّم ألوان وإضاءة وأجواء مختلفة.
- **7 شخصيات مرسومة بالكامل على Canvas:** كل مقاتل ذو silhouette وغطاء رأس وملابس وتسليح مختلف؛ حالات حركة وصدّ وضربات ورسوم مهارة خاصة.
- **مؤثرات قتال:** توهج، آثار حركة، ضربات، جسيمات، ضربات طاقة، تشويش بصري خفيف عند الاصطدام، وشاشة نتيجة محسنة.
- **واجهة محسنة:** بطاقات اختيار الشخصيات، معاينة VS، أشرطة الصحة والحراسة، مؤشر تبريد المهارة، هوية مرئية موحدة.
- **أداء:** رسم خلفية كل ساحة على لوحة Canvas مخبأة وإعادة استخدامها في إطارات القتال؛ الجزيئات المتحركة خفيفة.
- **اختبارات:** تشمل التصيير التجريبي لجميع الساحات والشخصيات وحالات الهجوم والدفاع، مع التحقق من عدم تعديل حالة المحرك خلال التصيير.

رسوم الشخصيات منفذة بالمتجهات برمجياً؛ لم تُستخدم صور جاهزة أو حقوق أطراف ثالثة. يظل التوازن الاحتمالي الفعلي للمواجهات مسألة قياس واختبار لعب، لا نتيجة يمكن ضمانها من الرسم فقط.
