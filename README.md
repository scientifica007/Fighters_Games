# صراع العناصر · Elemental Rivals

لعبة قتال ثنائية الأبعاد تعمل بالكامل داخل المتصفح، برسوم شخصيات أصلية مرسومة برمجياً على HTML5 Canvas. لا تحتاج إلى قاعدة بيانات أو حساب أو شبكة أثناء اللعب.

## اللعب

افتح [index.html](./index.html) على متصفح حديث، أو انشر المستودع عبر GitHub Pages. وقد تحتاج إلى تشغيل خادم ملفات محلي لأن اللعبة تستخدم وحدات JavaScript (ES modules):

~~~bash
python3 -m http.server 8000
~~~

ثم افتح http://localhost:8000 .

**الوضعان:**
- **الرحلة الفردية:** اختر واحداً من ستة مقاتلين، وواجه سبعة خصوم متصاعدة مهارتهم، وتنتهي الرحلة بمواجهة **نيكس، حارس البوابة**. أعلى مرحلة يتم الوصول إليها تُحفظ محلياً لكل مقاتل. يمكنك متابعة الرحلة أو إعادة بدئها.
- **القتال الثنائي المحلي:** يختار لاعبان شخصيتين من الشخصيات الست، ويتنافسان على الجهاز نفسه. الفائز بأول جولتين يفوز بالمباراة. يسمح بمرآة الشخصية نفسها.

## التحكم

| الفعل | اللاعب الأول | اللاعب الثاني |
|---|---|---|
| اليمين / اليسار | D / A | ← / → |
| القفز | W | ↑ |
| صد الهجمة (بالاستمرار في الضغط) | S | ↓ |
| ضربة خفيفة | F | J |
| ضربة ثقيلة | G | K |
| المهارة الخاصة | H | L |
| إيقاف مؤقت | P أو Esc | P أو Esc |

يتوافر تحكم لمسي على الهاتف، ويُفضل الوضع الأفقي. للمواجهة الثنائية، لوحة مفاتيح مشتركة أو شاشة واسعة.

## التوازن

تفرض النسخة الأولى مبدأ **التماثل العددي**: صحة جميع الشخصيات 100، وسرعة الحركة والقفز والضربات الأساسية مطابقة، وقيمة ضرر المهارة الخاصة وتبريدها متماثلتان (15 نقطة، 6.6 ثانية). تتفاوت مناطق التأثير والتوقيت والمنفعة التكتيكية وفق الشخصية. يزيد ذكاء خصوم القصة تدريجياً عبر **التوقيت والدفاع والمسافة**، وليس عبر مكافآت مخفية للصحة أو الضرر.

**مهم:** التماثل العددي لا يثبت أن كل مواجهة تمتلك احتمال فوز 50%. إثبات ذلك يحتاج إلى بيانات مباريات فعلية وتحليل matchups وضبط مستمر. تسمح بنية تعريف الشخصيات والتحكم باختبار هذه الفرضية لاحقاً.

## مكوّنات المشروع

- index.html: واجهة اللعبة العربية والمتجاوبة.
- style.css: تصميم الواجهة الداكنة.
- fighters.js: الشخصيات، المهارات، ثوابت التوازن، مراحل القصة.
- render.js: رسم شخصيات متمايزة بصرياً والساحة والمؤثرات والعدادات.
- game.js: محرك القتال والإدخال والذكاء الاصطناعي والحفظ والصوت.
- tests/balance.test.mjs: اختبارات قواعد التوازن.
- .github/workflows/ci.yml: فحوصات JavaScript والتوازن.

## خصوصية وإتاحة

- لعبة محلية بالكامل، دون اتصالات شبكية أو تحليلات أو أصول من أطراف ثالثة.
- يستخدم localStorage لحفظ المرحلة المكتملة فقط.
- أُخذت الحركة المخفضة في الحسبان في الواجهة؛ المؤثرات القتالية الرسومية جزء من المشهد.
- جميع الشخصيات والتصميمات أصلية لهذا المشروع.

**ملاحظة تشغيلية:** فتح index.html مباشرة بصيغة file:// قد يُحظر بسبب الاستيراد المحلي للوحدات في بعض المتصفحات. استعمل خادم الملفات المذكور أو GitHub Pages.
